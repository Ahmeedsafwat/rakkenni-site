# Rakkenni (ركّني) website

Landing page for Rakkenni, smart parking for Egyptian cities: book ahead in garages, malls, airports and events, or park now in street zones.

- Demo app: https://parkapp-egypt.expo.app
- Single self-contained `index.html` (fonts from Google Fonts), ready for GitHub Pages.

To preview locally:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
